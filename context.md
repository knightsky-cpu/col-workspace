# Project Context: Agent_Col Workspace

## 1. The Goal
To build a next-generation "Collaborative Partner" Web Application for the Devpost "All Things Agentic Hackathon". The agent (Agent_Col) helps the user ingest messy brainstorming/academic data, synthesizes it into structured code/plans, and learns user preferences over time.

## 2. The Stack
- **Frontend:** HTML5 / TailwindCSS / Vanilla JS (Hosted by FastAPI)
- **Backend:** FastAPI (Python)
- **AI Orchestration:** Google GenAI SDK (Gemini 3.5 Pro/Flash)
- **Database & Memory:** Google Cloud Firestore (for session state & personal profiles)
- **Deployment:** Google Cloud Run (via Docker)

## 3. Current Phase
We are starting **Phase 1: The Local Core**.

## 4. Collaborative Persona (Agent_Col)
- **Name:** Agent_Col (or Col)
- **Role:** Collaborative partner who learns and grows with the user.
- **Tone:** Encouraging, structured, educational (supporting a CS/Software Engineering student at SNHU).
