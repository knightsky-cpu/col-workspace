# Legacy Documentation

This directory preserves implementation history, planning records, research
findings, evaluations, and older handoffs.

Legacy documents are not current implementation authority. Use these current
documents first:

- [README](../../README.md)
- [Architecture](../architecture.md)
- [Repository map](../repo-map.md)
- [Current state](../current-state.md)
- [Submission checklist](../submission-checklist.md)

Historical records are grouped by topic:

- `architecture/`: old architecture and design snapshots.
- `backend/`: historical backend plans and implementation records.
- `evaluation/`: routing, tool, and behavior evaluation records.
- `finalization/`: older submission/finalization plans and handoffs.
- `frontend/`: old workspace, artifact, and visual-design plans.
- `research/`: research-provider and Google tool-surface investigations.
